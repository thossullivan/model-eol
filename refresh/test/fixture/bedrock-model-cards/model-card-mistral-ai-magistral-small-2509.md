## Model Details
<a name="model-card-mistral-ai-magistral-small-2509-details"></a>

Magistral Small 2509 is Mistral AI's reasoning model that uses chain-of-thought to solve complex math, coding, and logic problems. For more information about model development and performance, see the [model/service card](https://docs.mistral.ai/getting-started/models).
+ **Model launch date:** Sep 2025
+ **EOL no sooner than:** Sep 2026
+ **Legacy period:** at least 6 months
+ **Model lifecycle policy:** [Model lifecycle (For Models Launched Prior to Sept 7 2026)](model-lifecycle-legacy.md)
+ **Model EOL date:** N/A
+ **End User License Agreements and Terms of Use:** [View](https://aws.amazon.com/legal/bedrock/third-party-models/)
+ **Model lifecycle:** Active
+ **Context window:** 128K tokens
+ **Max output tokens:** 40K
+ **Reasoning:** Supported
